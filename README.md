# RembayungAR

RembayungAR is an Augmented Reality cooking assistance application developed using Unity, Vuforia, and ARCore.

## Features
- Marker-Based AR recipe scanning
- 3D food visualization
- Ingredient and nutritional information
- Markerless AR cooking simulation
- Interactive cooking guidance

## Technologies Used
- Unity
- Vuforia Engine
- ARCore
- C#
